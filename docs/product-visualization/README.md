# Field Chase product visualizations

This directory is documentation-only. It does not change the game runtime, build process, dependencies, or existing product files.

## Visuals

- [Product mind map](./product-mindmap.md) — product structure, current experience, systems, and possible future directions.
- [Gameplay workflow](./gameplay-workflow.md) — the player journey and game-state transitions.
- [Product roadmap](./product-roadmap.md) — a proposed Now / Next / Later planning view.
- [Markmap source](./fieldchase-markmap.md) — an outline that can be opened with a Markmap-compatible editor for an interactive, collapsible mind map.

## How to edit

### Mermaid diagrams

Open any Mermaid Markdown file on GitHub, select the pencil icon, edit the text inside the `mermaid` block, and commit the change to a branch. GitHub renders the updated diagram directly in the Markdown preview.

### Markmap

Edit `fieldchase-markmap.md` as ordinary Markdown headings and bullet points. A Markmap-compatible editor or extension can turn it into an interactive mind map without changing the game code.

## Scope

The current-state sections are based on the existing repository README and browser-game files. Items explicitly labelled as opportunities, questions, or roadmap candidates are planning suggestions rather than implemented features.
